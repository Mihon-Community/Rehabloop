# Synthetic keypoint sequences

Labelled, fully synthetic 2D landmark traces for deterministic testing of the
movement engine and fixture mode. No real person, patient or approved footage.

- `seated_knee_extension_synthetic.json` — four frames per cycle: REST, EXTENDING,
  TARGET_HOLD, RETURNING. Coordinates are illustrative, not clinical values.
- Every consumer must label output derived from these files as **simulated**.
